🌟 Once Upon a Pointer...
In the vast universe of Data Structures, there exists a humble yet mighty structure — the Linked List. Unlike its rigid cousin the Array, the Linked List doesn't demand contiguous memory. Instead, it whispers to each node: "Find your own space, but remember where the next one lives."

This repository is my journey log 📖 through the twisting, turning, pointer-chasing world of Linked Lists. Every file here is a battle fought, a bug squashed, a concept conquered. 💪

Meet our heroes:

🟢 Node — The fundamental building block, holding data and a pointer to its neighbor

🎯 Head — The gatekeeper, the entry point, the first of his name

🏁 Tail — The end of the line, pointing to the void (NULL)

➡️ Next — The magic thread that ties everything together

⬅️ Prev — The nostalgic one (in Doubly Linked Lists) who remembers the past
